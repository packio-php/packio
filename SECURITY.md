# Security policy

## Supported versions

Packio is in 0.x. Security fixes are released only for the latest release.

## Report a vulnerability privately

Please report a vulnerability privately, either by email to [info@packio.us](mailto:info@packio.us) or through GitHub: open the repository's Security tab and choose Report a vulnerability. Include a concise description and safe reproduction steps. Do not disclose the issue in a public issue, pull request, discussion, or commit message while it may affect users.

Include the affected Packio commit or version and, for container deployments, the image tag and digest when available. Describe the impact and prerequisites. Remove or mask credentials and personal data. Do not attach environment files, database dumps, package archives, authorization headers, tokens, session cookies, or unredacted mail bodies.

There is no published response-time commitment, disclosure deadline, or bug bounty. The maintainer will assess reports and coordinate any public disclosure after investigating the affected versions and available fixes.

## Supported deployment scope

See [docs/support.md](docs/support.md) for the supported, experimental and unsupported configurations.
