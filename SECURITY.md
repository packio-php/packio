# Security policy

Packio is preparing for its first public release. A stable release and a security maintenance window have not been announced. The current intended deployment and runtime scope is documented in the [support matrix](docs/support.md); historical version tags do not establish a security support period.

## Report a vulnerability privately

Please email [info@packio.us](mailto:info@packio.us) with a concise description and safe reproduction steps. This is the maintainer's existing private reporting address. Do not disclose the issue in a public issue, pull request, discussion, or commit message while it may affect users.

Include the affected Packio commit or version and, for container deployments, the image tag and registry digest when available. Describe the impact and prerequisites. Remove or mask credentials and personal data. Do not attach environment files, database dumps, package archives, authorization headers, tokens, session cookies, or unredacted mail bodies.

There is no published response-time commitment, disclosure deadline, bug bounty, or supported-version window. The maintainer will assess reports and coordinate any public disclosure after investigating the affected versions and available fixes.

## Supported deployment scope

Use [docs/support.md](docs/support.md) for the current first-release target and unsupported or experimental configurations. This policy does not imply a stable release or a maintenance promise for historical tags.
